**FSP Improved**

> *Because the official portal is so broken it felt like a personal insult.*

> [!WARNING]
> **Vibe-coded software ahead.** Proceed at your own risk!

**Features**

* 🌙 **Dark Mode** – High-contrast, OLED-friendly styling that won't blind you during late-night study sessions.
* 📱 **Mobile & Screen Reader First** – Full WCAG compliance. Tested with TalkBack and VoiceOver using actual ARIA roles, proper focus traps, and interactive backdrops—no unlabelled `<div>` traps or ghost buttons.
* 🕵️ **Hidden Metadata Unlocked** – Directly exposes raw backend API payloads that the official UI hides.
* ⚡ **Snappy Local Rendering** – Intercepts data at the transport layer for instant client-side state updates.
* 🔓 **AGPL-3.0 Licensed** – Free and open-source forever. No closed-source forks, no telemetry, no spyware, no commercial paywalls.

**Installation**

1. Install a userscript manager like **Violentmonkey** or **Tampermonkey** on desktop or mobile Firefox.
2. Click **[FSP Improved.user.js](https://github.com/thetommylong/fsp-improved/releases/latest/download/script.user.js)**.
3. Open the portal and enjoy a usable UI.
